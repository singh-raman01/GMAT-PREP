# Part of the Question Bank is held back for Mocks

A Mock score means little when its Questions have been seen before, and practice can exhaust a local Question Bank. A quarter of each Section's Questions, spread across Question Types and Difficulty Bands, forms the Mock Reserve: Mocks and Sectionals draw from it first, and Practice Sets cannot use it until the Curator releases it. Membership is decided per Stimulus, so an RC passage's Questions stay together, and each new Book or generation batch contributes a quarter of its Questions the same way. A Reserve Question a Profile has already Seen, in a Session or through a Paper Mark, opens to that Profile's Practice Sets, because holding it back no longer protects anything for that Profile. When the Reserve runs short of unseen Questions near the needed Difficulty, a Mock uses any unseen Question, then the one Seen longest ago, and its report counts the repeats. Expected result: Mock scores rest on unseen Questions, and the report says when they don't. Releasing is one-way, because a released Question cannot become unseen again.
